# Airbnb Price Data — Exploratory Analysis with Pandas

## 🎯 Project Goal
Initial hands-on practice with the **Pandas** library: loading, exploring, and manipulating a real-world dataset of Airbnb prices across various European cities.

## 📊 Dataset
[Airbnb Prices in European Cities](https://www.kaggle.com/datasets/thedevastator/airbnb-prices-in-european-cities) (Kaggle)

## 🛠️ Key Tasks & Accomplishments
- Automated dataset download via the Kaggle API.
- Data loading and structured representation using Pandas DataFrames.
- Initial Exploratory Data Analysis (EDA): inspecting data types, handling missing values, and generating descriptive statistics.
- Data manipulation, column selection, and custom filtering.

## 🧰 Tech Stack
`Python` `Pandas` `Kaggle API`
